# PU Syllabus Finder — V1 Category Architecture

Student flow:

Course → Category → Semester → Subject → Search → Syllabus

Data is separated by course and category:

data/syllabus/ba/dsc.json
data/syllabus/ba/mdc.json
data/syllabus/ba/sec.json
data/syllabus/ba/vac.json
data/syllabus/ba/compulsory.json

The same structure is prepared for B.Sc., B.Com. and BBA.

The JSON files are currently placeholders. Replace them only with verified PU syllabus data.
